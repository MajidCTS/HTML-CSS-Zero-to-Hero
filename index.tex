\markboth{پیشگفتار}{پیشگفتار}

\pandocbounded{\includegraphics[keepaspectratio]{assets/images/cover.webp}}

هدف از نگارش این کتاب آشنایی تخصصی با HTML و مکمل‌های آن یعنی CSS و
JavaScript است. به دلیل گستردگی مبحث جاوا اسکریپت بعد از صحبت درباره این
دو پیش نیاز درباره آن در کتاب دیگری صحبت خواهیم کرد. HTML-CSS اهمیت
زیادی دارند چون وب‌سایت‌ها تبدیل به یکی از مهم‌ترین رابط‌ها شده‌اند و
مرورگرها عضو جدایی ناپذیر سیستم‌های عامل شده‌اند و رقابت سختی بین آنها
فراگیر شده تا تبدیل به مرورگر پیش فرض کاربران شوند.

بدون توجه به اینکه در کدام حوزه فناوری اطلاعات در حال
\href{https://roadmap.sh/}{توسعه فردی} خود هستید HTML-CSS در عصر حاضر
قسمتی از اطلاعات عمومی شما خواهند بود در صورتی که زمانی فقط طراحان وب به
این مباحث نیاز حیاتی داشتند. آشنایی با آنها شما را قادر می‌سازد به
پتانسیل بالقوه آنها آگاهی پیدا کنید. فردی که در حوزه IT فعالیت می‌کند
باید به این توانایی‌ها آشنایی داشته باشد تا جعبه ابزار کامل‌تری در اختیار
داشته باشد.

این کتاب به درد چه کسانی می‌خوره؟

\begin{itemize}
\item
  مبتدیان جسور

  افرادی که به تازگی وارد دنیای برنامه‌نویسی وب شده‌اند. همه آنچه درباره
  HTML-CSS باید بدانند در این کتاب وجود دارد.
\item
  Backend Developers

  برنامه‌نویسانی که معمولاً با سرور و پایگاه داده کار می‌کنند و قصد دارند
  یک آشنایی سریع و کاربردی با بخش Front پیدا کنند. اگر xaml یا razor و
  \ldots{} را دیده باشید خواهید دید که به عنوان یک توسعه دهنده سمت سرور
  باید به عنوان بخشی از مبانی وب با این دو مبحث آشنا باشید.
\item
  Frontend developers
\item
  طراحان وب
\item
  کسانی که به دنبال مرجع به روز هستند

  در این کتاب سعی شده به روزترین تغییرات حوزه HTML-CSS همواره گردآوری
  شده و در دسترس متخصصین این حوزه قرار گیرد. مطالب قبلی بر اساس این
  تغییرات به روز نگه داشته می‌شوند تا آخرین تغییرات مرورگرها و جدیدترین
  قابلیت‌های این دو حوزه در اختیار شما قرار گیرند.
\end{itemize}

این کتاب برای چه کسانی نیست: اگر به دنبال کتابی هستید که صرفاً تگ‌های HTML
را لیست کرده باشد، این کتاب برای شما نیست. اما اگر می‌خواهید وب‌سایتی
بسازید که در موبایل و دسکتاپ عالی دیده شود، با سیستم‌عامل کاربر هماهنگ
بشه و رفتارهای هوشمندانه داشته باشد، خوش آمدید! این کتاب برای شما نوشته
شده است. از قابلیت‌های Git روی پروژه‌های مرتبط با HTML و CSS نیز می‌توان
استفاده کرد. برای آشنایی با Git
\href{https://docs.google.com/document/d/1A13cY3E68Fkwm99M8EopNOU3njukQOxHsjsHXvvTSvs/edit?tab=t.0}{این
کتاب} را مطالعه بفرمایید. یکی دیگر از ابزارهای مفید در این حوزه
Developer tools مرورگرها است. برای آشنایی با آن از
\href{https://docs.google.com/document/d/1HIPhxZSNIG8TZAbeFuuqap98xHlXUrjdPoaoGinG2z0/edit?tab=t.0}{این
کتاب} استفاده کنید.

\chapter{مقدمه}\label{ux645ux642ux62fux645ux647}

html یک زبان استاندارد \textbf{نشانه گذاری} سمت کاربر است که از آن برای
ایجاد صفحات وب و برنامه‌های کاربردی وب، با استفاده از CSS و جاوا اسکریپت
استفاده می‌کنند. مرورگرهای وب اسناد HTML را از یک سرور وب یا از سیستم
رایانه دریافت می کنند و اسناد را به صفحات وب چندرسانه ای تبدیل می کنند.
عناصر HTML ساختار یک صفحه وب را توصیف می کنند و در اصل شامل نشانه هایی
برای ظاهر سند هستند.

تاکنون نسخه هایی از آن منتشر شده است که \textbf{html5} آخرین نسخه از آن
می باشد.

ساختار تگ های HTML به این صورت است:

\begin{Shaded}
\begin{Highlighting}[]
\DataTypeTok{\textless{}}\KeywordTok{tag}\DataTypeTok{\textgreater{}}
\NormalTok{  ...}
\DataTypeTok{\textless{}/}\KeywordTok{tag}\DataTypeTok{\textgreater{}}
\end{Highlighting}
\end{Shaded}

که داخل کاراکتر های باز و بسته نام عناصر و داخل تگ محتوای آن قرار می
گیرد.تگ های HTML معمولا به صورت جفتی مانند

و \textless/ p\textgreater{} قرار می گیرند. اولین تگ در یک جفت تگ شروع
است، برچسب دوم تگ پایان است. تگ پایان مانند تگ شروع بوده، اما قبل از اسم
تگ وارد شده است.گاهی نیز به شکل \textless/\textgreater{} استفاده شده و
اصطلاحا \textbf{self close} هستند مثلا:

\begin{Shaded}
\begin{Highlighting}[]

\end{Highlighting}
\end{Shaded}
